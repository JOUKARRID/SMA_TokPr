# TP3 : Prompt Engineering & Analyse de Sentiments

**Auteur :** JOUKARRID MOHAMMED

## Objectif
Utiliser des LLMs (Qwen 2.5 via Ollama) pour classifier des avis (positifs/négatifs) et tester l'impact du Prompt Engineering.

## Technologies
- Python, Jupyter Notebook
- LangChain
- Ollama (Modèle local : qwen2.5:7b)

## Contenu
- `prompttoken.ipynb` : Le notebook avec le code et les tests.
- `Capture d'installation...png` : Preuve d'installation du modèle.
- `README.md` : Explication du projet.

## Lancer le projet
1. Installer Ollama.
2. Télécharger le modèle : `ollama pull qwen2.5:7b`
3. Ouvrir et exécuter `prompttoken.ipynb`.

## Résultats
Les prompts structurés (avec rôle et exemples) améliorent la précision du modèle sur la classification des sentiments IMDb.
